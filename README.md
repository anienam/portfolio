# Anienamakan Udo — Frontend Developer Portfolio

A responsive, static portfolio built with semantic HTML, CSS, and vanilla JavaScript.

## Run locally

Open `index.html` in a browser, or serve the folder with any static file server.

## Structure

- `index.html` — portfolio content and project links
- `css/style.css` — responsive layout, theme, cards, forms, and accessibility states
- `js/main.js` — mobile navigation and dynamic footer year
- `assets/` — profile photo, logo, and project preview images
- `thank-you.html` — contact form confirmation page

## Featured work

- Unitellas website
- Flama CBT Platform
- TrashBeta
- SkillLink

Smaller practice projects are grouped separately below the featured projects.

## Deployment

This is a static site and can be deployed to Vercel, GitHub Pages, Netlify, or another static host. Confirm the contact form's Formspree endpoint and the project demo links before publishing.
